# My 90-Day Cloud & DevOps Learning Plan

**Start Date:** June 10, 2026
**Current Level:** Master's in Computer Science (Illinois Institute of Technology) — building practical Cloud and DevOps skills through hands-on learning.

## What DevOps Means to Me

To me, DevOps is not just a job title. It's the ability to understand the entire software lifecycle—from writing code to deploying, monitoring, and improving applications in production.

I enjoy the idea of automation, infrastructure, cloud platforms, and solving real-world problems. What excites me most is being able to build something from scratch, automate the process, and watch it move all the way to production.

DevOps combines development, cloud, networking, automation, and problem-solving into one discipline, which is why I find it so interesting.

## Why I'm Learning Cloud & DevOps

I recently completed my Master's in Computer Science and am currently on F-1 OPT in the United States.

My goal is to build a strong career in Cloud Engineering, DevOps, Platform Engineering, and AI Infrastructure. While I have academic knowledge, I want to develop real-world engineering skills that companies actually use.

I believe the best way to learn is by building, documenting, and sharing the journey publicly. This repository will serve as both my learning journal and my proof of consistency.

## Core Skills I'm Building

### Linux

Learn the operating system that powers most cloud infrastructure.

### Networking

Build a strong understanding of networking concepts, troubleshooting, DNS, HTTP, TCP/IP, routing, and cloud networking.

### Git & GitHub

Master version control and collaboration workflows used by engineering teams.

### Docker

Learn containerization and create efficient Dockerfiles and container-based applications.

### Kubernetes

Understand container orchestration, deployments, services, scaling, and troubleshooting.

### AWS Cloud

Gain hands-on experience with core AWS services including EC2, VPC, IAM, S3, RDS, Lambda, and CloudWatch.

### CI/CD

Learn how modern software delivery pipelines work using GitHub Actions and automation tools.
